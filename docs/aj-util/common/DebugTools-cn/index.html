DebugTools

DebugTools 提供当前 JVM 运行环境的轻量诊断信息。

if (DebugTools.isChinaTimeZone()) {
    // JVM 默认时区为 Asia/Shanghai / GMT+08:00。
}

if (DebugTools.isDebug) {
    // 开发模式行为。
}

isDebug 在类加载时初始化：通常在非 Unix/Linux 系统中为 true，在 Unix/Linux 类系统中为 false。设置环境变量 AJAXJS_TEST=true 可强制其为 true。它是可变的公开字段，应用可有意识地覆盖，但应尽早并保持一致地设置。

isChinaTimeZone() 检查的是 JVM 默认时区；它不会修改默认时区，也不能用来判断用户的语言环境或实际所在地。
