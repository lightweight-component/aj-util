AJ Utilities 简介

轻量级 Java 8+ 工具库。在需要保存配置或状态的场景中，API 采用小而清晰的对象；无状态操作则保持简洁。项目提供源码、Javadoc 与单元测试。

领域 主要 API 说明
编码与摘要 Base64Utils、StringBytes、UrlCodec、HashHelper Base64、十六进制、URL 参数、消息摘要与 HMAC。
常用工具 ConvertBasicValue、ObjectHelper、MapTool、RandomTools、StrUtil、RegExpHelper 类型转换、对象、Map、随机值、字符串与带缓存的正则表达式。
结构化数据 JsonUtil、XmlHelper 可替换 JSON 引擎与安全的 XML 工具。
日期时间 DateTools、DateTypeConvert、Formatter Java 8 时间格式化、严格解析和新旧日期类型转换。
I/O FileHelper、ResourceHelper、DataReader、DataWriter、ZipHelper、UnzipHelper 文件、类路径资源、流、ZIP 压缩和带保护的 ZIP 解压。
密码学 DoCipher、AesGcm、AesCbc、AesPbe、AesLegacy、Rsa、SecretKeyMgr、RestoreKey、PemUtils、DoSignature、DoVerify AES、基于密码的加密、RSA-OAEP、密钥与签名；详见密码学指南。
反射 Clazz、Fields、Methods、NewInstance、Types 类加载、成员查找、对象构造与泛型类型检查。
日志 Trace、TextBox、EnableOperationLog MDC 链路上下文、格式化文本框与操作日志标记注解。

HTTP 请求、上传、下载和注解代理现属于独立的 AJ HTTP 工程。Java 包名仍为 com.ajaxjs.util.httpremote，但需要单独依赖；请参阅 AJ HTTP 安装指南。

安装

需要 Java 8+ 或以上。Maven 坐标：

<dependency>
    <groupId>com.ajaxjs</groupId>
    <artifactId>ajaxjs-util</artifactId>
    <version>1.3.8</version>
</dependency>

aj-util，开源框架 AJ-Framework 的一部分。联系方式： frank@ajaxjs.com，作者博客
