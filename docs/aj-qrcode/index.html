aj-qrcode

aj-qrcode is a dependency-free, Java 8 compatible encoder for QR Code Model 2. It is based on Nayuki's QR Code generator, supports versions 1–40 and all four error-correction levels, and offers both a normal API and a compact fast encoder.

The module generates symbols only. It does not scan/decode QR codes, create web responses, write SVG files automatically, or overlay logos.
