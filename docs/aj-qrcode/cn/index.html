aj-qrcode

aj-qrcode 是一个兼容 Java 8、无第三方运行时依赖的 QR Code Model 2 编码器。实现基于 Nayuki QR Code generator，支持版本 1–40、四种纠错等级，并提供常规 API 与更紧凑的 fast 编码器。

该模块只负责生成二维码，不提供扫描/解码、Web 响应输出、自动写入 SVG 文件或 Logo 叠加功能。

依赖

<dependency>
    <groupId>com.ajaxjs</groupId>
    <artifactId>aj-qrcode</artifactId>
    <version>1.4</version>
</dependency>
